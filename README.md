# QUI Evrima Database v0.5

## Büyük DinoDen güncellemesi

- Oynanabilir dinozor sayısı **22** oldu.
- **Austroraptor** eklendi.
- 22 dinozorun Prime ağırlık / hız / Bite Force değerleri kullanıcının The Dino Den oyun içi profil ekranlarından işlendi.
- Deinosuchus Prime verisi özel olarak **%100 Prime** şeklinde etiketlendi.
- Triceratops özel değerleri **%92 growth** olarak etiketlendi ve büyük kafa avantajı notu eklendi.
- Normal / Prime arayüzü sadeleştirildi.
- Tüm 22 dinozor için görsel dosyası pakete eklendi.
- Carnivore / Herbivore / Omnivore kategori kartlarına ayrı sinematik kapak görselleri eklendi.
- DinoDen hassas değerleri kullanıldı (ör. Allosaurus 201,26; Carnotaurus 172,52; Omniraptor 74,76).
- Mutation build önerileri bu sürümde hâlâ eklenmedi.
